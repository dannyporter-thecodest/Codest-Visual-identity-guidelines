# Case study intake form

**For Delivery.** Fill this in for one project so Cody can write its case study. Write in plain words, the way you would explain the project to a colleague. Facts only: if you are not sure, write "not sure" rather than guessing. Cody uses your words for names and terms, so call things what the client calls them.

**Required** fields are the minimum for a case study. Everything else makes it stronger. Leave a field empty if the answer is not available.

Fill in the **Answer** column. The examples show the level of detail needed; they are not facts about your project. Return the form to Danny.
